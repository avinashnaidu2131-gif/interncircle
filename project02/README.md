# Project 02: Data Visualization with Matplotlib & Seaborn

Charts built from the `tips` dataset, each matched to a question. Titles state the finding, one colour-blind-friendly palette is used throughout, and every chart has a written takeaway.

## Files
- `project02_visualization.ipynb` / `.html`: the notebook.
- `tips_overview.png`: 2 x 2 dashboard (histogram, box plot, scatter plot, annotated correlation heatmap), saved at 150 dpi.
- `tips_bar_charts.png`: bar charts (tip rate by day, bill by party size).

## Run
```bash
pip install pandas numpy seaborn matplotlib jupyter
jupyter notebook project02_visualization.ipynb
```
