# Project 03: Customer Churn / Sales Trend Analysis

Analyses an e-commerce order table: monthly revenue trend, category comparison, the top-customer share (80/20 idea), a simple inactive-customer (churn) check, three recommendations backed by numbers, and a one-page business brief.

**Data note:** the data is *generated* (simulated), not real customer data, so the recommendations show the method rather than real business facts.

## Files
- `project03_sales_analysis.ipynb` / `.html`: the notebook.
- `business_brief.md`: one-page brief (Context, Key findings, Recommendations, Next steps).
- `monthly_revenue.png`, `category_revenue.png`, `top_customers.png`: charts.

## Run
```bash
pip install pandas numpy seaborn matplotlib jupyter
jupyter notebook project03_sales_analysis.ipynb
```
